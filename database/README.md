# Database Layer (`database/`)

> **Role:** Persistent data store configuration for ResearchForge.  
> **Status:** Core Prisma schema defined — PostgreSQL initialized with `pgvector` extension and core data models (`User`, `Paper`, `PaperEmbedding`, `Workspace`).

---

## Purpose

The `database/` module houses the Prisma ORM configuration, schema definitions, and migration files for ResearchForge. It connects to a PostgreSQL instance with the `pgvector` extension enabled for relational, vector, and graph storage patterns.

---

## Core Data Models

The Prisma schema (`prisma/schema.prisma`) defines the following core models:

### 1. `User` (`users`)
- **Purpose:** Manages researcher accounts, JWT authentication credentials, and workspace ownership.
- **Key Fields:** `id` (cuid), `email` (unique), `password`, `name`, `createdAt`, `updatedAt`.
- **Relations:** 1-to-many with `Workspace`.

### 2. `Paper` (`papers`)
- **Purpose:** Persists metadata for academic research papers ingested via DOI, arXiv, or URL.
- **Key Fields:** `id` (cuid), `title` (indexed), `abstract`, `authors` (`String[]`), `doi` (unique), `arxivId` (unique), `url`, `publicationDate`, `journal`, `citationCount`, timestamps.
- **Relations:** 1-to-many with `PaperEmbedding`, many-to-many with `Workspace`.

### 3. `PaperEmbedding` (`paper_embeddings`)
- **Purpose:** Stores 384-dimensional dense vector embeddings generated by `sentence-transformers` (`all-MiniLM-L6-v2`) for semantic search via `pgvector`.
- **Key Fields:** `id` (cuid), `paperId` (indexed foreign key), `embedding` (`vector(384)`), `model`, timestamps.
- **Referential Action:** `onDelete: Cascade` (deleting a paper cascades to remove its vector embeddings).

### 4. `Workspace` (`workspaces`)
- **Purpose:** Represents personal reading lists and collaborative paper collections.
- **Key Fields:** `id` (cuid), `name`, `description`, `userId` (indexed foreign key), timestamps.
- **Relations:** Belongs to `User` (`onDelete: Cascade`), many-to-many with `Paper`.

## Service Responsibilities

- **Current (M1.5):** Prisma schema definitions (`prisma/schema.prisma`) targeting PostgreSQL + `pgvector` with core models (`User`, `Paper`, `Workspace`, `PaperEmbedding`).
- **Future (M2+):** Database migrations, initial seed data, raw SQL pgvector similarity search queries, and graph indexing configurations.

## How to Run & Apply Migrations

```bash
# From the backend/ directory (or root via pnpm):
cd ../backend

# Validate Prisma schema
npx prisma validate --schema=../database/prisma/schema.prisma

# Generate Prisma Client types
pnpm prisma generate

# Create and apply a new migration (when DB is running)
pnpm prisma migrate dev --name init

# Seed the database with benchmark research papers
pnpm run db:seed
```
