# Security Policy

## Current Project Stage

ResearchForge is currently in planning and early development under **IEEE Summer of Code 2026**. No runnable production code or live web service exists at this stage.

As implementation begins in Milestone 2, we take security seriously and welcome vulnerability reports from the community.

## Reporting a Vulnerability

If you discover a potential security vulnerability in ResearchForge, please report it responsibly:

1. **Do NOT open a public GitHub Issue** for security vulnerabilities.
2. Contact the lead maintainer directly via GitHub ([@JanmejaiPratapTonk-123](https://github.com/JanmejaiPratapTonk-123)).
3. Include the following details in your report:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any proposed remediation

## Response SLA

- **Initial Acknowledgment:** Within **24 to 48 hours**.
- **Assessment & Triage:** Within **5 business days**.
- **Fix & Public Advisory:** Dependent on vulnerability severity.

Thank you for helping keep ResearchForge secure!
